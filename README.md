# NutriTrack - Vanilla Calorie & Macro Tracker

A clean, responsive, and fully client-side calorie and macronutrient tracker built with 100% vanilla HTML5, CSS3, and modern JavaScript.

## Features

- **Daily Calorie & Macro Tracking**: Monitor consumed vs. target calories and remaining budget with visual indicators.
- **Macronutrients Split**: Real-time progress bars for Protein, Carbohydrates, and Fats.
- **Hydration Tracker**: 8-cup water intake logging with quick +250ml / -250ml controls.
- **Categorized Meals**: Organize logs across Breakfast, Lunch, Dinner, and Snacks with live search and serving multipliers.
- **Quick Food Presets**: Integrated library of 18+ common foods for one-click logging.
- **7-Day Analytics**: HTML5 Canvas chart displaying daily intake vs. target goal line, weekly averages, and active streaks.
- **Client-Side Persistence**: Fully powered by browser `localStorage` without external server dependencies.
- **Data Export & Import**: Backup and restore data anytime using JSON.

## Tech Stack

- **HTML5**
- **CSS3** (Pure vanilla, zero CSS variables, zero frameworks)
- **JavaScript (ES6+)** (Zero libraries, vanilla DOM & Canvas API)

## Getting Started

Simply open `index.html` in any modern web browser.
